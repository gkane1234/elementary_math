# Constructive rationals (L2/L3)

- **D=0** `L2`: $\frac{3x + 3}{x - 3}$ → $\frac{3x + 3}{x - 3}$
- **D=2** `L2`: $\frac{-3x + 6}{x - 1}$ → $\frac{-3x + 6}{x - 1}$
- **D=4** `L2`: $\frac{2x - 4}{x - 1}$ → $\frac{2x - 4}{x - 1}$
- **D=4** `L2`: $\frac{x^{2} - 4x + 3}{x^{2} - x}$ → $\frac{x - 3}{x},\; x \neq 1$
- **D=6** `L2`: $\frac{x}{x - 3}$ → $\frac{x}{x - 3}$
- **D=6** `L2`: $\frac{3x^{2} - 9x + 6}{x^{2} - 1}$ → $\frac{3x - 6}{x + 1},\; x \neq 1$
- **D=8** `L2`: $\frac{-x - 3}{x}$ → $\frac{-x - 3}{x}$
- **D=8** `L2`: $\frac{-2\left(x\right)\left(x - 2\right)\left(x - 1\right)}{x^{2} - 4x + 3}$ → $\frac{-2x^{2} + 4x}{x - 3},\; x \neq 1$
- **D=10** `L2`: $\frac{3x^{2} - 12x + 9}{x}$ → $\frac{3x^{2} - 12x + 9}{x}$
- **D=10** `L2`: $\frac{2\left(x\right)\left(x - 2\right)\left(x - 3\right)}{\left(x - 1\right)\left(x + 2\right)\left(x - 3\right)}$ → $\frac{2x^{2} - 4x}{x^{2} + x - 2},\; x \neq 3$
- **D=14** `L2`: $\frac{3x^{2} + 3x}{x + 2}$ → $\frac{3x^{2} + 3x}{x + 2}$
- **D=14** `L2`: $\frac{2\left(x - 2\right)\left(x - 3\right)\left(x + 1\right)}{x^{2} + x}$ → $\frac{2x^{2} - 10x + 12}{x},\; x \neq -1$
- **D=20** `L2`: $\frac{2x}{x - 1}$ → $\frac{2x}{x - 1}$
- **D=20** `L2`: $\frac{2\left(x + 1\right)\left(x - 1\right)\left(x - 3\right)}{x^{2} - x - 6}$ → $\frac{2x^{2} - 2}{x + 2},\; x \neq 3$
