# Agent instructions

## Commit requested changes to main

When implementing a requested change, commit and push it to main. Do not open a pull request unless the user explicitly asks for one.

## Changes apply to all topics

When the user asks for a change to question generation, previews, worksheets, variety, formatting, or similar behavior, the change applies to ALL topics unless they explicitly name a subset. Do not implement it only for the example they mentioned (for example Grade 6 ratios, or only calculus derivatives).
