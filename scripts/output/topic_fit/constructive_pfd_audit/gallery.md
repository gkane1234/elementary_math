# Constructive PFD (L4)

- **D=0** `L4`: $\frac{5x - 7}{x^{2} - 3x + 2}$ → $\frac{3}{x - 2}+\frac{2}{x - 1}$
- **D=2** `L4`: $\frac{3x - 3}{x^{2} - x - 2}$ → $\frac{1}{x - 2}+\frac{2}{x + 1}$
- **D=4** `L4`: $\frac{12x + 12}{3x^{2} - 12}$ → $\frac{1}{x + 2}+\frac{3}{x - 2}$
- **D=6** `L4`: $\frac{x + 4}{x^{2} - 2x}$ → $\frac{3}{x - 2}+\frac{-2}{x}$
- **D=8** `L4`: $\frac{6x^{2} + 18}{2\left(x + 3\right)\left(x - 3\right)\left(x\right)}$ → $\frac{2}{x + 3}+\frac{2}{x - 3}+\frac{-1}{x}$
- **D=10** `L4`: $\frac{3x^{2} - 8x + 6}{\left(x - 1\right)\left(x - 2\right)\left(x\right)}$ → $\frac{-1}{x - 1}+\frac{1}{x - 2}+\frac{3}{x}$
- **D=14** `L4`: $\frac{6x^{2} + 12x - 18}{2\left(x + 1\right)\left(x - 3\right)\left(x\right)}$ → $\frac{-3}{x + 1}+\frac{3}{x - 3}+\frac{3}{x}$
- **D=20** `L4`: $\frac{6x^{2} + 2x - 2}{\left(x - 1\right)\left(x + 1\right)\left(x\right)}$ → $\frac{3}{x - 1}+\frac{1}{x + 1}+\frac{2}{x}$
