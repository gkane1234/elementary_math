# All topics gallery

Open [gallery.html](gallery.html) in Chrome. This markdown file does not include the diagrams.

The HTML page has up to two questions for each ready topic. Topics whose notes open with unclear or low variety are in the In development section, marked (context) and/or (variety), instead of their course sections. Where a question has a figure, a number line, or a coordinate graph, that drawing is on the card with the words. Graphing questions that ask the student to draw the line show a blank plane on the prompt and the line on the answer.
