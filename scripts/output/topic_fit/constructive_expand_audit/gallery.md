# Constructive expand/simplify (L1 affine)

- **D=0** `L1`: $3 + x$ → $x + 3$
- **D=2** `L1`: $x + 3$ → $x + 3$
- **D=4** `L1`: $-3x - 6 + 2\left(x + 3\right)$ → $-x$
- **D=6** `L1`: $-x - 6 + 3\left(x + 2\right)$ → $2x$
- **D=8** `L1`: $3x + 5 + \left(x + 1\right)\left(-2\right)$ → $x + 3$
- **D=10** `L1`: $4x + 10 + \left(x + 3\right) * -3$ → $x + 1$
- **D=14** `L1`: $\left(-x + 1\right)2$ → $-2x + 2$
- **D=20** `L1`: $\left(x - 1\right)2 + -x - 1$ → $x - 3$
